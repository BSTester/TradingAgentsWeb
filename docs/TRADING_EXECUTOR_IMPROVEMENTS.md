# 交易执行Agent改进说明

## 改进日期
2025-11-06

## 改进内容

### 1. ✅ 执行决策与实际操作一致性强化

**问题：**
- 之前可能出现报告显示"买入"但实际未执行订单的情况
- 执行决策与实际操作不匹配，误导用户

**解决方案：**
- 强制要求报告中的"执行决策"必须与实际调用的API一致
- 明确规则：
  - 调用了 `place_futu_order` → 报告"已执行"（买入/卖出/卖空）
  - 未调用 `place_futu_order` → 报告"跳过执行"或"持仓观望"
  - 禁止报告"买入"或"卖出"如果没有实际下单

**报告格式要求：**
```
## I. 执行决策
- **决策结果**: [必须与实际操作一致]
  * 已执行 - 仅当实际调用了 place_futu_order
  * 跳过执行 - 当决定不交易时
  * 持仓观望 - 当决定保持现有仓位不变时
- **实际执行动作**: [必须与实际操作一致]
  - 买入建仓 (仅当无持仓且执行了买入)
  - 加仓买入 (仅当有持仓且执行了买入)
  - 减仓卖出 (仅当有持仓且执行了卖出)
  - 清仓卖出 (仅当执行了全部卖出)
  - 卖空开仓 (仅当美股市场且执行了卖空)
  - 持仓不变 (未执行任何交易)
  - 跳过交易 (决定不执行)
```

### 2. ✅ 美股卖空操作支持

**功能说明：**
- 美股市场支持卖空（做空）操作
- 港股和A股不支持卖空操作

**卖空操作逻辑：**

#### A. 开空仓（无持仓 → 卖空）
```
风控建议：-15%（做空15%）
当前持仓：无
操作：直接卖空开仓
订单：place_futu_order(trd_side=1, qty=shares)
报告：卖空开仓
```

#### B. 平多开空（多头 → 空头）
```
风控建议：-15%（做空15%）
当前持仓：+10%（多头10%）
操作：先平多仓，再开空仓
步骤1：place_futu_order(trd_side=1, qty=current_long_shares) - 平多仓
步骤2：place_futu_order(trd_side=1, qty=target_short_shares) - 开空仓
报告：平多仓后卖空开仓
```

#### C. 加空仓（空头 → 更大空头）
```
风控建议：-20%（做空20%）
当前持仓：-10%（空头10%）
操作：增加空头仓位
订单：place_futu_order(trd_side=1, qty=additional_shares)
报告：加空仓
```

#### D. 减空仓（空头 → 较小空头）
```
风控建议：-10%（做空10%）
当前持仓：-20%（空头20%）
操作：减少空头仓位（部分平空）
订单：place_futu_order(trd_side=0, qty=cover_shares)
报告：减空仓
```

#### E. 平空开多（空头 → 多头）
```
风控建议：+15%（做多15%）
当前持仓：-10%（空头10%）
操作：先平空仓，再开多仓
步骤1：place_futu_order(trd_side=0, qty=current_short_shares) - 平空仓
步骤2：place_futu_order(trd_side=0, qty=target_long_shares) - 开多仓
报告：平空仓后买入开多
```

### 3. ✅ 市场限制处理

**港股和A股卖空限制：**
```
如果风控建议：-15%（做空）
市场类型：HK 或 CN
操作：跳过执行
报告："跳过执行 - 港股/A股不支持卖空操作"
```

### 4. ✅ 仓位方向标识

**仓位比例符号含义：**
- `+15%` = 多头仓位（LONG）15%
- `-15%` = 空头仓位（SHORT）15%
- `0%` = 空仓（无持仓）

### 5. ✅ 禁止操作

**同方向往返交易（禁止）：**
- ❌ 卖出100%多头 → 立即买入（同方向往返）
- ❌ 平仓100%空头 → 立即卖空（同方向往返）

**方向转换（允许）：**
- ✅ 平多仓 → 开空仓（方向转换）
- ✅ 平空仓 → 开多仓（方向转换）

## 技术实现

### 订单参数说明
```python
place_futu_order(
    stock_code="AAPL",
    trd_side=0,  # 0=买入(BUY), 1=卖出(SELL)
    qty=100,     # 数量
    price=150.0, # 价格（限价单）
    order_type=0 # 0=限价单, 1=市价单
)
```

### 卖空操作示例
```python
# 开空仓（卖空）
place_futu_order(stock_code="AAPL", trd_side=1, qty=100)

# 平空仓（买入平仓）
place_futu_order(stock_code="AAPL", trd_side=0, qty=100)
```

## 测试建议

### 测试场景1：执行决策一致性
1. 提交分析任务，风控建议买入
2. 检查执行报告中的"执行决策"
3. 验证：如果实际下单 → 报告"已执行"；如果未下单 → 报告"跳过执行"

### 测试场景2：美股卖空
1. 提交美股分析任务（如AAPL）
2. 风控建议做空（负仓位比例）
3. 验证：执行卖空操作，报告显示"卖空开仓"

### 测试场景3：港股卖空限制
1. 提交港股分析任务（如00700.HK）
2. 风控建议做空
3. 验证：跳过执行，报告显示"港股不支持卖空操作"

### 测试场景4：方向转换
1. 已有多头仓位，风控建议做空
2. 验证：先平多仓，再开空仓
3. 报告显示"平多仓后卖空开仓"

## 注意事项

1. **卖空风险**：卖空操作风险较高，理论上损失无上限，需谨慎使用
2. **保证金要求**：卖空需要足够的保证金，系统会自动检查
3. **市场限制**：只有美股支持卖空，港股和A股不支持
4. **报告准确性**：执行报告必须准确反映实际操作，不能误导用户
