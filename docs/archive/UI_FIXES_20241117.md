# UI问题修复 - 2024年11月17日

## 修复的问题

### 1. 排名开关无法正常工作 ✅

**问题描述**：
- 用户点击"参加排名"开关
- 显示成功提示但开关状态不变
- 刷新页面后开关仍然是关闭状态

**根本原因**：
开关使用了Tailwind的`peer-checked:`伪类，但在某些情况下CSS选择器不能正确工作。

**修复方案**：
改用基于React状态的条件渲染，直接根据`participateInLeaderboard`状态来控制样式。

**修改文件**: `web/frontend/src/app/intraday-trading/page.tsx`

**修改前**：
```tsx
<div className="w-10 h-5 bg-dark-tertiary rounded-full shadow-inner transition-all duration-300 ease-in-out peer-checked:bg-accent-primary peer-focus:outline-none peer-focus:ring-2 peer-focus:ring-accent-primary/20">
  <div className="w-4 h-4 bg-white rounded-full shadow-md transform transition-transform duration-300 ease-in-out translate-y-0.5 peer-checked:translate-x-5"></div>
</div>
```

**修改后**：
```tsx
<div className={`w-10 h-5 rounded-full shadow-inner transition-all duration-300 ease-in-out ${
  participateInLeaderboard ? 'bg-accent-primary' : 'bg-dark-tertiary'
}`}>
  <div className={`w-4 h-4 bg-white rounded-full shadow-md transform transition-transform duration-300 ease-in-out translate-y-0.5 ${
    participateInLeaderboard ? 'translate-x-5' : 'translate-x-0.5'
  }`}></div>
</div>
```

**优点**：
- ✅ 直接基于React状态，更可靠
- ✅ 不依赖CSS伪类选择器
- ✅ 更容易调试和维护
- ✅ 视觉反馈更即时

### 2. LLM API密钥默认可见 ✅

**问题描述**：
- 在智能盯盘的配置面板中
- LLM API密钥默认是明文显示
- 存在隐私和安全风险

**根本原因**：
`showLlmApiKey`状态初始值设置为`true`，注释说是"默认显示密钥用于验证"，但这不符合安全最佳实践。

**修复方案**：
将`showLlmApiKey`的初始值改为`false`，默认隐藏密钥。

**修改文件**: `web/frontend/src/components/intraday/ControlPanel.tsx`

**修改前**：
```tsx
const [showLlmApiKey, setShowLlmApiKey] = useState(true); // 默认显示密钥用于验证
```

**修改后**：
```tsx
const [showLlmApiKey, setShowLlmApiKey] = useState(false); // 默认隐藏密钥保护隐私
```

**安全改进**：
- ✅ 默认隐藏敏感信息
- ✅ 用户需要主动点击眼睛图标才能查看
- ✅ 符合安全最佳实践
- ✅ 防止屏幕共享时泄露密钥

## 技术细节

### 排名开关实现

#### 状态管理
```tsx
const [participateInLeaderboard, setParticipateInLeaderboard] = useState<boolean>(
  user?.participate_in_leaderboard || false
);

// 同步用户数据
React.useEffect(() => {
  if (user) {
    setParticipateInLeaderboard(user.participate_in_leaderboard || false);
  }
}, [user]);
```

#### 样式控制
```tsx
// 背景色：根据状态切换
className={`... ${participateInLeaderboard ? 'bg-accent-primary' : 'bg-dark-tertiary'}`}

// 滑块位置：根据状态切换
className={`... ${participateInLeaderboard ? 'translate-x-5' : 'translate-x-0.5'}`}
```

#### 事件处理
```tsx
onChange={async (e) => {
  const newCheckedState = e.target.checked;
  setParticipateInLeaderboard(newCheckedState); // 立即更新UI
  
  try {
    // 调用API
    const response = await fetch(...);
    const result = await response.json();
    
    // 更新状态
    setParticipateInLeaderboard(result.participating);
    
    // 刷新用户数据
    if (refreshUser) {
      await refreshUser();
    }
    
    showToast(result.message, 'success');

    // 错误时回滚

}
```

### API密钥隐藏实现

#### 状态定义
```tsx
const [showLlmApiKey, setShowLlmApiKey] = useState(false); // 默认隐藏
```

#### 输入框类型
```tsx
<input
  type={showLlmApiKey ? 'text' : 'password'}
  value={llmApiKey}
  onChange={(e) => setLlmApiKey(e.target.value)}
/>
```

#### 切换按钮
```tsx

  type="button"
  onClick={() => setShowLlmApiKey(!showLlmApiKey)}

</button>
```
