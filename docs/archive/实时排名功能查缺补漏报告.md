### 问题3: 持仓数据缺少实时价格计算 ⭐⭐
**严重程度**: 中
**影响**: 持仓显示的价格、市值、盈亏都是0

**当前状态**: `public_leaderboard_routes.py` 中返回的持仓数据字段为0
```python
positions_data.append({
    "stock_code": position.stock_code,
    "market_type": position.market_type,
    "quantity": position.current_quantity,
    "current_price": 0.0,  # ❌ 需要获取实时价格
    "market_value": 0.0,   # ❌ 需要计算
    "unrealized_pnl": 0.0, # ❌ 需要计算

})
```

**解决方案**: 需要对接行情API获取实时价格

**建议实现**:
```python
# 在 public_leaderboard_routes.py 中添加
from tradingagents.dataflows.y_finance import YFinanceDataFlow

async def get_current_price(stock_code: str, market_type: str) -> float:
    """获取股票当前价格"""
    try:
        dataflow = YFinanceDataFlow()
        # 根据市场类型调整股票代码格式
        if market_type == 'HK':
            ticker = f"{stock_code}.HK"
        elif market_type == 'CN':
            ticker = stock_code  # 需要根据实际情况调整
        else:
            ticker = stock_code
        
        # 获取最新价格
        data = dataflow.get_stock_data(ticker, period='1d')
        if data and not data.empty:
            return float(data['Close'].iloc[-1])
    except Exception as e:
        print(f"获取价格失败 {stock_code}: {e}")
    return 0.0

# 在获取持仓时调用
current_price = await get_current_price(position.stock_code, position.market_type)
market_value = current_price * position.current_quantity
unrealized_pnl = market_value - (position.first_open_price * position.initial_quantity)
pnl_percentage = (unrealized_pnl / (position.first_open_price * position.initial_quantity)) * 100
```

### 问题5: 缺少数据初始化 ⭐
**严重程度**: 低
**影响**: 新用户或测试环境可能没有足够的历史数据

**解决方案**: 创建数据初始化脚本

**建议实现**:
```python
# scripts/init_leaderboard_data.py
"""初始化排名数据脚本"""
import asyncio
from datetime import datetime, timedelta
from web.backend.database import AsyncSessionLocal
from web.backend.models import User, AccountSnapshot

async def init_sample_data():
    """为测试用户创建30天的样本数据"""
    async with AsyncSessionLocal() as db:
        # 获取参与排名的用户
        from sqlalchemy import select
        result = await db.execute(
            select(User).where(User.participate_in_leaderboard == True)
        )
        users = result.scalars().all()
        
        for user in users:
            # 为每个用户创建30天的快照数据
            base_assets = 100000.0
            for i in range(30):
                date = datetime.now() - timedelta(days=29-i)
                # 模拟资产波动
                assets = base_assets * (1 + (i * 0.01))  # 简单增长模型
                
                snapshot = AccountSnapshot(
                    user_id=user.id,
                    market_type='US',
                    snapshot_date=date,
                    total_assets=assets,
                    cash=assets * 0.3,
                    market_value=assets * 0.7,
                    unrealized_pnl=assets * 0.05,
                    realized_pnl=0.0
                )
                db.add(snapshot)
        
        await db.commit()
        print(f"✅ 已为 {len(users)} 个用户初始化30天数据")

if __name__ == "__main__":
    asyncio.run(init_sample_data())
```
