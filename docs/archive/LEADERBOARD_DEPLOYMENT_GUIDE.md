## 🚀 完整部署步骤

### 前置要求
```bash
# 确保已安装依赖
pip install yfinance  # 用于获取股票价格
```

### 步骤1: 启动后端服务
```bash
# 在项目根目录
python web/backend/app.py
```

等待看到以下输出：
```
✅ Database tables initialized successfully
✅ Scheduler service started
✅ Leaderboard real-time update task started
INFO:     Uvicorn running on http://0.0.0.0:8000
```

### 步骤2: 启动前端服务（新终端）
```bash
cd web/frontend
npm run dev
```

等待看到：
```
ready - started server on 0.0.0.0:3000
```

### 步骤3: 设置演示数据
```bash
# 在新终端，项目根目录
python scripts/setup_leaderboard_demo.py
```

按提示操作：
1. 选择 `1` - 为所有用户开启排名并创建样本数据
2. 如果用户已有数据，选择 `y` 覆盖

### 步骤4: 验证功能
```bash
python scripts/verify_leaderboard_setup.py
```

应该看到：
```
✅ 所有检查通过！排名功能已就绪
```

### 步骤5: 访问页面测试
1. 打开浏览器访问: http://localhost:3000
2. 登录系统
3. 访问"实时排名"页面: http://localhost:3000/leaderboard
4. 查看趋势图和用户列表
5. 点击用户查看详细信息

## 📊 数据说明

### 样本数据特点
- **时间范围**: 30天历史数据
- **初始资产**: 80,000 - 150,000 美元（随机）
- **日波动**: -3% 到 +4%
- **趋势**: 轻微上升趋势（0.1%/天）
- **市场**: 随机分配 US/HK/CN

### 真实数据要求
如果要使用真实数据，需要：
1. 用户在智能盯盘中进行实际交易
2. 系统每天自动创建账户快照
3. 或手动调用快照API创建数据

## 🔧 常见问题解决

### Q1: 趋势图显示"暂无趋势数据"
**原因**: 用户没有历史快照数据
**解决**: 
```bash
python scripts/setup_leaderboard_demo.py
```

### Q2: 持仓价格显示为0
**原因**: 
- yfinance未安装
- 股票代码格式不正确
- 网络连接问题

**解决**:
```bash
pip install yfinance
# 检查后端日志查看具体错误
```

### Q3: WebSocket连接失败
**原因**: 后端服务未运行或端口被占用
**解决**:
```bash
# 检查后端是否运行
curl http://localhost:8000/docs

# 如果端口被占用，修改端口
# 在 web/backend/app.py 最后一行修改 port=8000
```

### Q4: 排名页面显示"暂无参与排名的用户"
**原因**: 没有用户开启排名
**解决**:
1. 登录系统
2. 进入"智能盯盘"页面
3. 开启"参加排名"开关
或运行:
```bash
python scripts/setup_leaderboard_demo.py
```
