# 排行榜模型名称显示位置最终调整

## 更新内容

将模型名称从用户名旁边移到金额下方，并添加固定宽度和文本溢出处理。

## 实现细节

### 布局结构

```
┌─ 排名卡片 ──────────────────────────┐
│ ┌─ 左侧 ─────┐  ┌─ 右侧 ──────────┐ │
│ │ 排名徽章   │  │ 资产金额        │ │
│ │ 用户名     │  │ 模型名称        │ │
│ │ 日期       │  │                 │ │
│ └────────────┘  └─────────────────┘ │
└────────────────────────────────────┘
```

### 代码实现

```tsx
{/* 用户信息 */}
<div className="text-left flex-1">
  <p className="text-sm font-medium text-text-primary">
    {user.username}
  </p>
  <p className="text-xs text-text-tertiary">
    {user.latest_snapshot_date}
  </p>
</div>

{/* 资产和模型 */}
<div className="text-right">
  <p className="text-sm font-semibold text-text-primary mb-1">
    ${user.total_assets.toLocaleString()}
  </p>
  {user.model_name && (
    <p className="text-xs text-accent-primary font-medium truncate max-w-[120px] ml-auto" title={user.model_name}>
      {user.model_name}
    </p>
  )}
</div>
```

## 样式说明

### 模型名称样式

| 属性 | 值 | 说明 |
|------|-----|------|
| `text-xs` | 12px | 小号字体 |
| `text-accent-primary` | 主题色 | 突出显示 |
| `font-medium` | 500 | 中等粗细 |
| `truncate` | text-overflow: ellipsis | 文本溢出显示省略号 |
| `max-w-[120px]` | 120px | 最大宽度限制 |
| `ml-auto` | margin-left: auto | 右对齐 |
| `title={user.model_name}` | - | 鼠标悬停显示完整名称 |

### 文本溢出处理

使用Tailwind的 `truncate` 类，相当于：

```css
overflow: hidden;
text-overflow: ellipsis;
white-space: nowrap;
```

**效果**：
- 短名称：`gpt-4-turbo` → 正常显示
- 长名称：`claude-3-opus-20240229` → `claude-3-opus-202...`
- 鼠标悬停：显示完整名称的tooltip

## 宽度说明

### 固定宽度：120px

**原因**：
1. **适配常见模型名称**：
   - `gpt-4-turbo` (约80px)
   - `claude-3-opus` (约90px)
   - `gemini-pro` (约70px)

2. **避免布局破坏**：
   - 超长名称不会挤压其他元素
   - 保持卡片整体布局稳定

3. **响应式考虑**：
   - 在小屏幕上也能正常显示
   - 不会导致横向滚动

### 可调整宽度

如果需要调整宽度，修改 `max-w-[120px]`：

```tsx
// 更宽：150px
max-w-[150px]

// 更窄：100px
max-w-[100px]

// 响应式宽度
max-w-[100px] md:max-w-[120px] lg:max-w-[150px]
```
