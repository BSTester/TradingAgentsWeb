# 市场状态消息更新 - 显示完整交易时间

## 更新内容

修改了市场状态消息，现在会显示完整的交易时间，让用户更清楚地了解市场的交易时段。

## 消息格式对比

### 美股（US）

**修改前**：
- 开市中：`美股市场开市中（美东时间 10:30）`
- 未开市：`美股市场未开市（开市时间：9:30 美东时间，当前：08:45）`
- 已收市：`美股市场已收市（收市时间：16:00 美东时间，当前：17:30）`

- 开市中：`美股市场开市中（交易时间：9:30-16:00 美东时间，当前：10:30）`

## 改进点

### 1. 信息完整性 ✅
- 所有状态消息都包含完整的交易时间
- 用户无需记忆各市场的交易时段
- 一目了然地了解市场何时开市

### 2. 一致性 ✅
- 所有状态（开市、未开市、已收市、周末休市）都使用统一的格式
- 都包含"交易时间"字段
- 都显示当前时间（周末除外）

### 3. 用户体验 ✅
- 新用户可以快速了解交易时间
- 减少用户查询交易时间的需求
- 提供更多上下文信息

## 消息结构

### 通用格式

```
[市场名称]市场[状态]（交易时间：[时间段] [时区]，当前：[当前时间]）
```

### 周末格式

```
[市场名称]市场周末休市（交易时间：周一至周五 [时间段] [时区]）
```
