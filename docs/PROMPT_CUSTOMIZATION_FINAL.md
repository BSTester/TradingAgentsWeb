# Agent 提示词自定义功能 - 最终版本

## 🎉 功能完成

用户现在可以在智能盯盘的**系统配置弹窗**中自定义 Agent 的提示词和工具选择。

## 📍 访问方式

1. 访问智能盯盘页面：`http://localhost:3000/intraday-trading`
2. 点击控制面板上的"⚙️ 系统配置"按钮
3. 在弹窗中切换到"🤖 提示词配置" 标签页

## 🎯 功能特点

### 1. 集成到系统配置
- ✅ 与基础配置（富途API、LLM配置等）在同一个弹窗中
- ✅ 使用 Tabs 切换，界面统一
- ✅ 一个入口管理所有配置

### 2. 变量自动注入
- ✅ 用户**不需要关心变量**
- ✅ 系统在运行时自动注入必需的变量：
  - `{market_type}` - 市场类型 (US/HK/CN)
  - `{session_id}` - 会话ID
  - `{timestamp}` - 当前时间戳
  - `{user_id}` - 用户ID
- ✅ 用户只需编辑策略逻辑，无需处理技术细节

### 3. 完整的自定义能力
- ✅ 编辑策略名称和描述
- ✅ 编辑完整的系统提示词
- ✅ 选择 Agent 可以使用的工具（11个工具，按类别分组）
- ✅ 一键重置为默认配置

## 📋 使用步骤

### 步骤 1：打开系统配置
1. 在智能盯盘页面，点击"系统配置"按钮
2. 弹窗会显示两个标签页：
   - **基础配置**：富途API、LLM配置、分析间隔等
   - **提示词配置**：Agent 提示词和工具选择

### 步骤 2：切换到提示词配置
点击"🤖 提示词配置"标签页

### 步骤 3：编辑配置
1. **策略名称**：给你的策略起个名字（例如：激进型交易策略）
2. **策略描述**：简要描述策略特点
3. **系统提示词**：编辑 Agent 的行为逻辑
   - 定义交易哲学
   - 设置风险参数
   - 自定义决策逻辑
   - 调整执行流程
   - 修改输出格式
4. **工具选择**：勾选 Agent 可以使用的工具
   - 💰 账户工具（4个）
   - 📊 行情数据（3个）
   - 🔄 交易执行（包含在账户工具中）
   - 📰 新闻资讯（4个）

### 步骤 4：保存配置
点击"保存配置"按钮

### 步骤 5：应用配置
- 如果智能盯盘正在运行，停止后重新启动
- 新配置将在下次执行时生效

## 💡 使用示例

### 示例 1：创建保守型策略

1. 打开系统配置 → 提示词配置
2. 策略名称：`保守型交易策略`
3. 策略描述：`低风险，稳健收益，注重资本保护`
4. 修改提示词中的风险参数：
   ```
   ## Risk Parameters
   - Single stock: Maximum 20% (conservative)
   - Total exposure: Maximum 60%
   - Hard stop: -3% (tighter stop loss)
   ```
5. 工具选择：禁用 `place_futu_order`（只分析不交易）
6. 保存配置

### 示例 2：创建技术分析专家策略

1. 策略名称：`技术分析专家`
2. 策略描述：`纯技术分析，忽略新闻和基本面`
3. 修改提示词，增加技术指标权重
4. 工具选择：
   - ✅ 保持所有账户和行情工具
   - ❌ 禁用所有新闻工具
5. 保存配置

### 示例 3：创建新闻驱动策略

1. 策略名称：`新闻驱动策略`
2. 策略描述：`基于新闻和市场情绪的交易策略`
3. 修改提示词，强调新闻分析的重要性
4. 工具选择：
   - ✅ 启用所有新闻工具
   - ✅ 保持账户和行情工具
5. 保存配置

## 🔧 技术实现

### 变量自动注入机制

用户编辑的提示词会在运行时自动注入变量：

```python
# 后端自动处理
formatted_prompt = template.system_prompt.format(
    market_type=market_type,      # 自动注入
    session_id=session_id,          # 自动注入
    timestamp=datetime.now(),       # 自动注入
    user_id=user_id                 # 自动注入
)
```

用户只需要编辑策略逻辑，例如：
```
You are a conservative trader...

## Risk Parameters
- Maximum position: 20%
- Stop loss: -3%

## Trading Rules
- Only trade during market hours
- Avoid high volatility stocks
```

系统会自动添加必需的变量，用户无需关心。

## ⚠️ 注意事项

### 1. 配置生效时机
- 修改后需要**保存**才能生效
- 新配置将在**下次启动智能盯盘**时使用
- 如果智能盯盘正在运行，需要**停止后重新启动**

### 2. 提示词编辑建议
- ✅ 专注于策略逻辑和决策规则
- ✅ 无需关心变量注入
- ✅ 可以自定义执行流程和输出格式
- ❌ 不要手动添加变量（系统会自动处理）

### 3. 工具选择建议
- ✅ 至少保留账户工具（`get_futu_account_info`, `get_futu_positions`）
- ✅ 如果只想分析不交易，可以禁用 `place_futu_order`
- ✅ 根据策略需要选择行情和新闻工具

### 4. 重置功能
- 点击"重置为默认"会恢复系统默认提示词
- 当前修改将丢失，请谨慎操作
- 建议在重置前先复制保存当前提示词
