# 股票代码编码规则详解

## 概述

本文档详细说明了美股、港股和A股（沪市、深市）的股票代码编码规则，以及系统的验证逻辑。

---

## 一、美股（US Stock）

### 编码特点

- **格式**：1-5个字母（纯字母）
- **大小写**：不区分大小写，系统统一转为大写
- **特殊字符**：基本代码不包含特殊字符

### 交易所差异

#### NYSE（纽约证券交易所）
- **长度**：通常 1-3 个字母
- **示例**：
  - `F` - 福特汽车
  - `T` - AT&T
  - `IBM` - IBM
  - `JPM` - 摩根大通

#### NASDAQ（纳斯达克）
- **长度**：通常 4-5 个字母
- **示例**：
  - `AAPL` - 苹果
  - `MSFT` - 微软
  - `GOOGL` - 谷歌
  - `TSLA` - 特斯拉
  - `AMZN` - 亚马逊

### 特殊情况

- **第5个字母**：在某些情况下有特殊含义（如优先股、不同股票类别）
- **斜杠符号**：某些股票使用斜杠表示不同类别（如 `BRK/A`、`BRK/B`）
- **系统处理**：我们的系统只验证基本的1-5个字母格式

### 验证规则

```typescript
// 美股：1-5个字母
/^[A-Z]{1,5}$/.test(ticker)
```

## 二、港股（Hong Kong Stock）

### 编码特点

- **格式**：5位数字（2008年后统一）
- **历史**：2008年前为4位数字
- **范围**：00001-03999（主板）
- **后缀**：可选 `.HK`

### 板块分类

#### 主板（Main Board）
- **代码范围**：00001-03999
- **示例**：
  - `00700` / `00700.HK` - 腾讯控股
  - `00001` / `00001.HK` - 长和
  - `00005` / `00005.HK` - 汇丰控股
  - `09988` / `09988.HK` - 阿里巴巴

#### 创业板（GEM）
- **代码特征**：以 8 开头
- **示例**：
  - `08001` - 高门集团
  - `08083` - 中国有赞

### 特殊标识

港股名称后可能带有特殊字母标识：
- **B**：生物科技公司（未有收入）
- **W**：有认股权证
- **R**：人民币柜台

### 验证规则

```typescript
// 港股：4-5位数字（兼容旧格式）
/^\d{4,5}$/.test(ticker)

// 或带.HK后缀
ticker.endsWith('.HK') && /^\d{4,5}$/.test(base)
```

## 三、A股 - 沪市（Shanghai Stock Exchange）

### 编码特点

- **格式**：6位数字
- **后缀**：可选 `.SH`
- **交易所代码**：SSE

### 板块分类

#### 主板（Main Board）
- **代码前缀**：600、601、603、605
- **特点**：大型成熟企业
- **示例**：
  - `600000` / `600000.SH` - 浦发银行
  - `600519` / `600519.SH` - 贵州茅台
  - `601318` / `601318.SH` - 中国平安
  - `603288` / `603288.SH` - 海天味业
  - `605499` / `605499.SH` - 东鹏饮料

#### 科创板（STAR Market）
- **代码前缀**：688
- **特点**：科技创新企业
- **上市要求**：注册制
- **示例**：
  - `688001` / `688001.SH` - 华兴源创
  - `688008` / `688008.SH` - 澜起科技
  - `688036` / `688036.SH` - 传音控股

### 验证规则

```typescript
// 沪市：600、601、603、605、688开头
const prefix3 = ticker.substring(0, 3);
return ['600', '601', '603', '605', '688'].includes(prefix3);
```

## 四、A股 - 深市（Shenzhen Stock Exchange）

### 编码特点

- **格式**：6位数字
- **后缀**：可选 `.SZ`
- **交易所代码**：SZSE

### 板块分类

#### 主板（Main Board）
- **代码前缀**：000、001
- **特点**：大型企业
- **示例**：
  - `000001` / `000001.SZ` - 平安银行
  - `000002` / `000002.SZ` - 万科A
  - `000858` / `000858.SZ` - 五粮液

#### 中小板（SME Board）
- **代码前缀**：002
- **状态**：2021年4月已并入主板
- **特点**：中小型企业
- **示例**：
  - `002415` / `002415.SZ` - 海康威视
  - `002594` / `002594.SZ` - 比亚迪
  - `002475` / `002475.SZ` - 立讯精密

#### 创业板（ChiNext）
- **代码前缀**：300、301
- **特点**：创新型企业
- **上市要求**：注册制
- **示例**：
  - `300750` / `300750.SZ` - 宁德时代
  - `300059` / `300059.SZ` - 东方财富
  - `301234` / `301234.SZ` - 创业板新股

### 验证规则

```typescript
// 深市：000、001、002、300、301开头
const prefix3 = ticker.substring(0, 3);
return ['000', '001', '002', '300', '301'].includes(prefix3);
```

## 五、系统验证逻辑

### 验证流程

```
用户输入
    ↓
标准化处理（去空格、转大写）
    ↓
格式验证
    ↓
    ├─ 美股：1-5个字母 ✓
    ├─ 港股：4-5位数字或带.HK ✓
    ├─ A股：6位数字 + 前缀验证
    │   ├─ 沪市：600/601/603/605/688 ✓
    │   └─ 深市：000/001/002/300/301 ✓
    └─ 其他：拒绝 ✗
```

### 后缀验证

系统严格验证后缀与代码的匹配：

| 后缀 | 适用市场 | 验证规则 |
|------|---------|---------|
| `.HK` | 港股 | 4-5位数字 |
| `.SH` | 沪市 | 600/601/603/605/688开头 |
| `.SZ` | 深市 | 000/001/002/300/301开头 |

**错误示例**：
- ❌ `000001.SH` - 深市代码不能用沪市后缀
- ❌ `600000.SZ` - 沪市代码不能用深市后缀
- ❌ `300750.SH` - 创业板属于深市，不能用.SH

## 八、技术实现

### 前端验证（TypeScript）

```typescript
export function validateTicker(ticker: string): boolean {
  const normalized = normalizeTicker(ticker);
  
  // 港股验证
  if (normalized.endsWith('.HK')) {
    const base = normalized.slice(0, -3);
    return /^\d{4,5}$/.test(base);
  }
  
  // A股验证（6位数字 + 前缀规则）
  if (/^\d{6}$/.test(normalized)) {
    const prefix3 = normalized.substring(0, 3);
    return ['600', '601', '603', '605', '688',  // 沪市
            '000', '001', '002', '300', '301']  // 深市
            .includes(prefix3);
  }
  
  // A股带后缀验证
  if (normalized.endsWith('.SH') || normalized.endsWith('.SZ')) {
    const base = normalized.slice(0, -3);
    if (!/^\d{6}$/.test(base)) return false;
    
    const prefix3 = base.substring(0, 3);
    if (normalized.endsWith('.SH')) {
      return ['600', '601', '603', '605', '688'].includes(prefix3);
    } else {
      return ['000', '001', '002', '300', '301'].includes(prefix3);
    }
  }
  
  // 美股验证
  if (/^[A-Z]{1,5}$/.test(normalized)) {
    return true;
  }
  
  return false;
}
```

### 后端验证（Python）

```python
def validate_ticker(ticker: str) -> bool:
    ticker = normalize_ticker(ticker)
    
    # 港股验证
    if ticker.endswith('.HK'):
        base = ticker[:-3]
        return base.isdigit() and 4 <= len(base) <= 5
    
    # A股验证
    if ticker.isdigit() and len(ticker) == 6:
        prefix3 = ticker[:3]
        return prefix3 in ('600', '601', '603', '605', '688',
                          '000', '001', '002', '300', '301')
    
    # A股带后缀验证
    if ticker.endswith(('.SH', '.SZ')):
        base = ticker[:-3]
        if not (base.isdigit() and len(base) == 6):
            return False
        
        prefix3 = base[:3]
        if ticker.endswith('.SH'):
            return prefix3 in ('600', '601', '603', '605', '688')
        else:
            return prefix3 in ('000', '001', '002', '300', '301')
    
    # 美股验证
    if ticker.isalpha() and 1 <= len(ticker) <= 5:
        return True
    
    return False
```
