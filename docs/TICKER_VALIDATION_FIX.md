# 港股代码验证问题修复

## 问题描述

在分析配置页面，输入 5 位数字格式的港股代码（如 `00700`）会校验不通过，但提示信息说"数字和带.HK都可以"。

## 根本原因

在 `web/frontend/src/utils/tickerValidator.ts` 的 `validateTicker` 函数中，验证逻辑的顺序有问题：

### 原来的逻辑（错误）

```typescript
export function validateTicker(ticker: string): boolean {
  const normalized = normalizeTicker(ticker);
  
  // 1. 检查带 .HK 后缀的港股 ✅
  if (normalized.endsWith('.HK')) {
    const base = normalized.slice(0, -3);
    return /^\d{4,5}$/.test(base);
  }
  
  // 2. 检查 6 位数字的 A 股 ✅
  if (/^\d{6}$/.test(normalized)) {
    // ... A 股验证逻辑
  }
  
  // 3. 检查带后缀的 A 股 ✅
  if (normalized.endsWith('.SH') || normalized.endsWith('.SZ')) {
    // ... A 股后缀验证逻辑
  }
  
  // 4. 检查美股 ✅
  if (/^[A-Z]{1,5}$/.test(normalized)) {
    return true;
  }
  
  // ❌ 问题：没有检查纯数字的港股代码（4-5位）
  return false;
}
```

**问题**：当输入 `00700` 时：
1. 不以 `.HK` 结尾 → 跳过港股检查
2. 是 5 位数字，不是 6 位 → 跳过 A 股检查
3. 不以 `.SH` 或 `.SZ` 结尾 → 跳过 A 股后缀检查
4. 不是字母 → 跳过美股检查
5. **返回 `false`** ❌

## 解决方案

在美股检查之前，添加纯数字港股代码的检查：

### 修复后的逻辑（正确）

```typescript
export function validateTicker(ticker: string): boolean {
  const normalized = normalizeTicker(ticker);
  
  // 1. 检查带 .HK 后缀的港股 ✅
  if (normalized.endsWith('.HK')) {
    const base = normalized.slice(0, -3);
    return /^\d{4,5}$/.test(base);
  }
  
  // 2. 检查 6 位数字的 A 股 ✅
  if (/^\d{6}$/.test(normalized)) {
    // ... A 股验证逻辑
  }
  
  // 3. 检查带后缀的 A 股 ✅
  if (normalized.endsWith('.SH') || normalized.endsWith('.SZ')) {
    // ... A 股后缀验证逻辑
  }
  
  // 4. ✅ 新增：检查纯数字的港股代码（4-5位）
  if (/^\d{4,5}$/.test(normalized)) {
    return true;
  }
  
  // 5. 检查美股 ✅
  if (/^[A-Z]{1,5}$/.test(normalized)) {
    return true;
  }
  
  return false;
}
```

**修复后**：当输入 `00700` 时：
1. 不以 `.HK` 结尾 → 跳过
2. 是 5 位数字，不是 6 位 → 跳过 A 股检查
3. 不以 `.SH` 或 `.SZ` 结尾 → 跳过
4. **是 4-5 位数字 → 返回 `true`** ✅

## 总结

通过在验证逻辑中添加纯数字港股代码（4-5位）的检查，修复了 `00700` 等港股代码无法通过验证的问题。

修复后：
- ✅ `0700` 和 `00700` 都可以正常使用
- ✅ `0700.HK` 和 `00700.HK` 也可以正常使用
- ✅ 提示信息与实际验证逻辑一致
- ✅ 不影响 A 股和美股的验证

## 注意事项

1. **港股代码格式**
   - 2008年后统一为5位数字（如 `00700`）
   - 2008年前为4位数字（如 `0700`）
   - 两种格式都支持

2. **验证顺序很重要**
   - 先检查带后缀的代码
   - 再检查纯数字代码
   - 最后检查字母代码

3. **避免冲突**
   - 6位数字只能是A股
   - 4-5位数字只能是港股
   - 1-5个字母只能是美股
