   - 登录系统

   - 开启"参加排名"开关

2. **查看排名**
   - 点击导航栏"实时排名"
   - 查看趋势图和用户列表
   - 鼠标悬停查看高亮

3. **关闭排名**
   - 返回"智能盯盘"页面
