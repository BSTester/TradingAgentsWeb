# 港股代码标准化处理说明

## 功能概述

后端接口对港股代码进行自动标准化处理，确保所有港股代码统一带上 `.HK` 后缀。

## 处理规则

### 输入 → 输出

| 用户输入 | 验证通过 | 标准化后 | 说明 |
|---------|---------|---------|------|
| `0700` | ✅ | `0700.HK` | 4位数字自动添加后缀 |
| `00700` | ✅ | `00700.HK` | 5位数字自动添加后缀 |
| `0700.HK` | ✅ | `0700.HK` | 已有后缀保持不变 |
| `00700.HK` | ✅ | `00700.HK` | 已有后缀保持不变 |
| `9988` | ✅ | `9988.HK` | 4位数字自动添加后缀 |
| `09988` | ✅ | `09988.HK` | 5位数字自动添加后缀 |

### 非港股代码

| 用户输入 | 验证通过 | 标准化后 | 说明 |
|---------|---------|---------|------|
| `AAPL` | ✅ | `AAPL` | 美股保持不变 |
| `600519` | ✅ | `600519` | A股保持不变 |
| `600519.SH` | ✅ | `600519.SH` | A股带后缀保持不变 |
| `000001` | ✅ | `000001` | A股保持不变 |
| `300750.SZ` | ✅ | `300750.SZ` | A股带后缀保持不变 |

## 技术实现

### 新增函数

```python
def normalize_ticker_with_suffix(ticker: str) -> str:
    """
    标准化股票代码并添加市场后缀
    
    特殊处理：
    - 港股：4-5位纯数字自动添加 .HK 后缀
    - 其他市场：保持原样
    """
    normalized = normalize_ticker(ticker)
    
    # 如果已经带了.HK后缀，直接返回
    if normalized.endswith('.HK'):
        return normalized
    
    # 检查是否是港股（4-5位纯数字）
    if normalized.isdigit() and 4 <= len(normalized) <= 5:
        return f"{normalized}.HK"
    
    # 其他情况保持原样
    return normalized
```

### 处理流程

```
用户输入股票代码
    ↓
normalize_ticker() - 基础标准化（去空格、转大写）
    ↓
validate_ticker() - 格式验证
    ↓
normalize_ticker_with_suffix() - 添加市场后缀
    ↓
    ├─ 港股（4-5位数字）→ 添加 .HK
    ├─ 港股（已有.HK）→ 保持不变
    └─ 其他市场 → 保持不变
    ↓
存储到数据库 / 传递给分析引擎
```

## 注意事项

### 1. 验证顺序很重要

必须先验证，再添加后缀：

```python
# ✅ 正确顺序
ticker = normalize_ticker(request.ticker)
if not validate_ticker(ticker):
    raise HTTPException(...)
ticker = normalize_ticker_with_suffix(ticker)

# ❌ 错误顺序（会导致验证失败）
ticker = normalize_ticker_with_suffix(request.ticker)
if not validate_ticker(ticker):  # 可能验证失败
    raise HTTPException(...)
```

### 2. 前端不需要修改

前端验证逻辑保持不变，用户可以输入带或不带 `.HK` 的港股代码，都能通过验证。后端会自动标准化。

### 3. 历史数据兼容

如果数据库中已有不带 `.HK` 的港股代码，建议运行数据迁移脚本：

```python
# 数据迁移示例
async def migrate_hk_tickers():
    # 查找所有4-5位纯数字的ticker
    stmt = select(AnalysisRecord).filter(
        AnalysisRecord.ticker.regexp_match(r'^\d{4,5}$')
    )
    records = await db.execute(stmt)
    
    for record in records.scalars():
        # 添加.HK后缀
        record.ticker = f"{record.ticker}.HK"
    
    await db.commit()
```
