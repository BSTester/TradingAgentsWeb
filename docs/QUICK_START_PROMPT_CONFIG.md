# Agent 提示词配置 - 快速开始

## 🚀 快速访问

1. 访问智能盯盘页面：`http://localhost:3000/intraday-trading`
2. 点击"⚙️ 系统配置"按钮
3. 切换到"🤖 提示词配置" 标签页

## ✨ 功能说明

在提示词配置页面，你可以：

### 1. 编辑策略信息
- **策略名称**：给你的交易策略起个名字
- **策略描述**：简要描述策略特点

### 2. 自定义提示词
编辑 Agent 的系统提示词，定义：
- 交易哲学和风格
- 风险参数
- 决策逻辑
- 执行流程
- 输出格式

### 3. 选择工具
勾选 Agent 可以使用的工具：
- 💰 **账户工具**（4个）：账户信息、持仓、订单、下单
- 📊 **行情数据**（3个）：实时行情、K线、技术指标
- 📰 **新闻资讯**（4个）：热门新闻、热门股票

### 4. 保存和重置
- **保存配置**：保存当前修改
- **重置为默认**：恢复系统默认配置

## 💡 使用技巧

### 快速开始
1. 首次使用建议先查看默认提示词
2. 根据需要调整风险参数
3. 选择需要的工具
4. 保存配置
5. 重启智能盯盘测试效果

### 策略示例

#### 保守型策略
```
策略名称：保守型交易
策略描述：低风险，稳健收益

提示词修改：
- 降低单股仓位上限（20%）
- 收紧止损（-3%）
- 降低总仓位（60%）

工具选择：
- 禁用 place_futu_order（只分析不交易）
```

#### 激进型策略
```
策略名称：激进型交易
策略描述：高风险高收益，快速进出

提示词修改：
- 提高单股仓位上限（40%）
- 放宽止损（-8%）
- 提高总仓位（95%）

工具选择：
- 启用所有工具
```

#### 技术分析专家
```
策略名称：技术分析专家
策略描述：纯技术分析，忽略新闻

提示词修改：
- 强调技术指标权重
- 弱化新闻影响

工具选择：
- 启用账户和行情工具
- 禁用所有新闻工具
```

## ⚠️ 注意事项

1. **保存后生效**：修改需要保存才能生效
2. **重启应用**：保存后需要重启智能盯盘
3. **谨慎重置**：重置会丢失当前修改
4. **工具选择**：至少保留账户工具

## 🔧 技术说明

### 变量自动注入
系统会自动注入以下变量，无需手动添加：
- `{market_type}` - 市场类型
- `{session_id}` - 会话ID
- `{timestamp}` - 时间戳
- `{user_id}` - 用户ID

### 配置存储
- 每个用户有独立的配置
- 配置存储在数据库中
- 支持版本管理

### 多用户隔离
- 用户之间配置完全隔离
- 互不影响

## 📞 常见问题

**Q: 修改后没有生效？**
A: 确保已保存配置，并重启了智能盯盘

**Q: 如何恢复默认配置？**
A: 点击"重置为默认"按钮

**Q: 可以保存多个策略吗？**
A: 当前每个用户只能有一个激活的策略，建议将不同策略保存到本地文件

**Q: 工具选择有什么建议？**
A: 至少保留账户工具（账户信息、持仓），其他根据策略需要选择

**Q: 提示词可以多长？**
A: 没有严格限制，但建议保持简洁清晰
