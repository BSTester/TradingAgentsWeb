# 提示词系统最终版本

## 📋 概述

提示词系统现已完全实现自动化文档生成，所有工具描述使用中文，用户只需关注 Agent 行为配置。

## ✨ 核心特性

### 1. 中文工具描述
所有 11 个工具的描述已更新为中文：

**账户管理工具**
- `get_futu_account_info` - 获取富途账户信息，包括资金余额、持仓市值、盈亏等
- `get_futu_positions` - 获取富途持仓信息，包括股票代码、持仓数量、成本价、当前价、盈亏等
- `get_futu_orders` - 获取富途订单信息，可按状态筛选（全部/待成交/已成交/已撤销）
- `place_futu_order` - 下单交易，支持买入/卖出，市价单/限价单

**行情数据工具**
- `get_futu_quote` - 获取股票实时行情，包括最新价、涨跌幅、成交量、OHLC等
- `get_futu_kline` - 获取股票K线数据，支持多种时间周期（1分钟/5分钟/日线/周线等）
- `get_futu_technical_analysis` - 获取技术分析指标，支持MACD、RSI、布林带等常用指标

**新闻资讯工具**
- `get_futu_hot_news` - 获取富途热门财经新闻，支持中英文
- `get_futu_hot_stocks` - 获取富途热门股票榜单，发现市场热点
- `get_akshare_news` - 获取AkShare财经新闻，实时市场资讯
- `get_akshare_hot_stocks` - 获取AkShare热门股票（百度搜索热度），支持A股/港股/美股

### 2. 自动文档生成

系统会自动在用户提示词前添加两部分文档：

#### 📋 运行时变量说明
```
## 📋 运行时变量说明

以下变量会在执行时自动注入，无需手动编辑：

- `{market_type}` - 当前市场类型 (US/HK/CN)
- `{session_id}` - 当前会话的唯一标识符
- `{timestamp}` - 当前时间戳 (YYYY-MM-DD HH:MM:SS)
- `{user_id}` - 当前用户ID

这些变量可以在提示词中使用，系统会自动替换为实际值。
```

#### 🔧 可用工具说明
根据用户选择的工具自动生成，按类别分组：

```
## 🔧 可用工具说明

### 账户管理工具
- `get_futu_account_info` - 获取富途账户信息，包括资金余额、持仓市值、盈亏等
  * 参数: market_type
...

### 行情数据工具
- `get_futu_quote` - 获取股票实时行情，包括最新价、涨跌幅、成交量、OHLC等
  * 参数: stock_code
...
```

### 3. 智能适配

工具说明会根据用户选择的工具自动适配：

**场景 1: 只读模式（仅查询工具）**
- 只显示 `get_futu_account_info`, `get_futu_positions`, `get_futu_quote`, `get_futu_kline`
- 文档长度：~400 字符

**场景 2: 完整交易模式（所有工具）**
- 显示全部 11 个工具
- 文档长度：~1000 字符

**场景 3: 新闻分析模式（新闻+行情）**
- 只显示新闻和行情相关工具
- 文档长度：~300 字符

```

              ↓

└─────────────────────────────────────────┘
```

## 🎯 用户体验

### 用户需要做的
1. 打开"系统配置" → "提示词配置"
2. 编辑策略名称和描述
3. 编辑 Agent 行为配置（提示词内容）
4. 选择需要的工具
5. 保存配置

### 系统自动完成的
1. ✅ 添加运行时变量说明
2. ✅ 根据选择的工具生成工具使用说明
3. ✅ 注入运行时变量（market_type, session_id, timestamp, user_id）
4. ✅ 组合成完整的系统提示词
