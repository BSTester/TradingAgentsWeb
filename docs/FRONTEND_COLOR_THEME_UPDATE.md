# 前端买卖主题色更新

## 更新日期
2025-11-06

## 颜色方案

### 新颜色定义
- **买入（BUY）**: `#f03a55` → `#d91744` (红色渐变)
- **卖出（SELL）**: `#00a870` → `#008c5e` (绿色渐变)
- **持有/观望（HOLD）**: `#f59e0b` → `#d97706` (黄色渐变，保持不变)

### 设计理念
采用中国股市传统配色：
- 🔴 **红色代表买入** - 符合中国投资者习惯（红涨）
- 🟢 **绿色代表卖出** - 符合中国投资者习惯（绿跌）
- 🟡 **黄色代表观望** - 中性色调

## 技术说明

### Tailwind CSS 自定义颜色
使用 `[#hexcode]` 语法直接在 className 中使用自定义颜色：
```tsx
className="bg-[#f03a55]"  // 直接使用十六进制颜色
className="from-[#f03a55] to-[#d91744]"  // 渐变色
```

### 颜色一致性
所有相关组件使用相同的颜色值，确保整个应用的视觉一致性。

## 注意事项

1. **颜色对比度**: 新颜色在白色背景上有良好的对比度，符合WCAG可访问性标准
2. **文化适应**: 红涨绿跌符合中国投资者的视觉习惯
3. **品牌一致性**: 颜色方案在所有页面保持一致
4. **打印友好**: PDF导出时颜色正确显示（使用 `printColorAdjust: 'exact'`）
