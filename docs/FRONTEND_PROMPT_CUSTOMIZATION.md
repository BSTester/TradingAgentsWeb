# 前端提示词自定义功能使用指南

## 📱 功能概述

用户现在可以通过 Web 界面完全自定义智能盯盘 Agent 的行为，包括：
- 编辑完整的系统提示词
- 选择 Agent 可以使用的工具
- 自定义交易策略和风险参数

## 🎯 访问方式

### 方法 1：从智能盯盘页面进入
1. 访问智能盯盘页面：`http://localhost:3000/intraday-trading`
2. 点击右上角的"设置"按钮
3. 进入设置页面

### 方法 2：直接访问
直接访问：`http://localhost:3000/intraday-trading/settings`

## 🔧 功能说明

### 1. 提示词配置

**位置**：设置页面 → "📝 提示词配置" 标签

**功能**：
- **模板名称**：给你的策略起个名字（例如：激进型交易策略）
- **描述**：简要描述策略特点
- **系统提示词**：完整的 Agent 提示词（支持 Markdown 格式）

**可用变量**：
- `{market_type}` - 市场类型 (US/HK/CN)
- `{session_id}` - 会话ID
- `{timestamp}` - 当前时间戳
- `{user_id}` - 用户ID

**操作**：
- **保存修改**：保存当前编辑的提示词
- **重置为默认**：恢复系统默认提示词
- **刷新**：重新加载最新的提示词

**标签页**：
- **编辑模式**：编辑提示词内容
- **预览模式**：查看格式化后的提示词
- **变量说明**：查看可用变量的说明

### 2. 工具选择

**位置**：设置页面 → "🔧 工具选择" 标签

**功能**：
选择 Agent 可以使用的工具，工具按类别分组：

- **💰 账户工具** (4个)
  - `get_futu_account_info` - 获取账户信息
  - `get_futu_positions` - 获取持仓信息
  - `get_futu_orders` - 获取订单信息
  - `place_futu_order` - 下单

- **📊 行情数据** (3个)
  - `get_futu_quote` - 获取实时行情
  - `get_futu_kline` - 获取K线数据
  - `get_futu_technical_analysis` - 获取技术指标

- **📰 新闻资讯** (4个)
  - `get_futu_hot_news` - 获取热门新闻
  - `get_futu_hot_stocks` - 获取热门股票
  - `get_akshare_news` - 获取财经新闻
  - `get_akshare_hot_stocks` - 获取热搜股票

**操作**：
- **全选**：启用所有工具
- **全不选**：禁用所有工具
- **单独勾选**：点击复选框启用/禁用单个工具
- **保存选择**：保存工具选择配置

## 💡 使用示例

### 示例 1：创建保守型交易策略

1. 进入设置页面
2. 在"提示词配置"中：
   - 模板名称：`保守型交易策略`
   - 描述：`低风险，稳健收益，注重资本保护`
   - 修改提示词中的风险参数：
     ```
     ## Risk Parameters
     - Single stock: Maximum 20% (conservative)
     - Total exposure: Maximum 60%
     - Hard stop: -3% (tighter stop loss)
     - Soft stop: -2%
     ```
3. 在"工具选择"中：
   - 禁用 `place_futu_order`（只分析不交易）
   - 保持其他工具启用
4. 点击"保存修改"和"保存选择"

### 示例 2：创建技术分析专家策略

1. 进入设置页面
2. 在"提示词配置"中：
   - 模板名称：`技术分析专家`
   - 描述：`纯技术分析，忽略新闻和基本面`
   - 修改提示词，增加技术指标权重
3. 在"工具选择"中：
   - 禁用所有新闻工具（`get_futu_hot_news`, `get_akshare_news` 等）
   - 保持账户和行情工具启用
4. 保存配置

### 示例 3：创建新闻驱动策略

1. 进入设置页面
2. 在"提示词配置"中：
   - 模板名称：`新闻驱动策略`
   - 描述：`基于新闻和市场情绪的交易策略`
   - 修改提示词，强调新闻分析的重要性
3. 在"工具选择"中：
   - 启用所有新闻工具
   - 可以禁用部分技术分析工具
4. 保存配置

## ⚠️ 注意事项

### 配置生效时机
- 修改配置后需要**保存**才能生效
- 新配置将在**下次启动智能盯盘**时使用
- 如果智能盯盘正在运行，需要**停止后重新启动**才能应用新配置

### 提示词编辑建议
1. **备份原始提示词**：在修改前先复制保存到本地
2. **测试修改**：先做小范围修改，测试效果后再大幅调整
3. **保留变量**：确保保留 `{market_type}` 等必要变量
4. **语法检查**：注意 Markdown 格式和缩进

### 工具选择建议
1. **账户工具必选**：至少保留 `get_futu_account_info` 和 `get_futu_positions`
2. **交易工具谨慎**：如果只想分析不交易，可以禁用 `place_futu_order`
3. **行情工具推荐**：建议保留 `get_futu_quote` 和 `get_futu_kline`
4. **新闻工具可选**：根据策略需要选择是否启用

## 🔄 重置配置

如果配置出现问题或想恢复默认：

1. 进入设置页面
2. 在"提示词配置"中点击"重置为默认"
3. 在"工具选择"中点击"全选"后保存
4. 重新启动智能盯盘

## 📊 配置效果验证

修改配置后，可以通过以下方式验证：

1. **查看决策报告**：
   - 启动智能盯盘
   - 查看生成的决策报告
   - 确认 Agent 的行为符合预期

2. **检查工具调用**：
   - 查看 Agent 调用了哪些工具
   - 确认禁用的工具没有被调用

3. **对比历史记录**：
   - 对比修改前后的决策差异
   - 评估新策略的效果

## 🚀 高级用法

### 1. 多策略管理
虽然当前每个用户只能有一个激活的模板，但可以通过以下方式管理多个策略：
- 将不同策略的提示词保存到本地文件
- 需要切换时，复制粘贴到编辑器并保存
- 未来可能支持多模板切换功能

### 2. 策略分享
可以导出提示词配置分享给其他用户：
1. 复制提示词内容
2. 记录启用的工具列表
3. 分享给其他用户
4. 其他用户粘贴并保存

### 3. 版本控制
建议使用 Git 或其他版本控制工具管理提示词：
- 每次重大修改前保存一个版本
- 记录修改原因和效果
- 方便回滚和对比

## 📞 技术支持

如果遇到问题：
1. 检查浏览器控制台是否有错误
2. 确认已登录且有权限
3. 尝试刷新页面
4. 重置为默认配置后重试
