# 排行榜折线图UI修复

## 问题描述

1. **标题重叠**：折线图左上角的标题与图例文字重叠，导致显示混乱
2. **Y轴刻度不清晰**：Y轴使用缩写（如"100K"），导致所有刻度看起来都一样，无法区分数值大小

## 修复方案

### 1. 调整布局间距

**文件**：`web/frontend/src/components/leaderboard/LeaderboardTrendChart.tsx`

**修改前**：
```typescript
const padding = { top: 60, right: 40, bottom: 60, left: 80 };
```

**修改后**：
```typescript
const padding = { top: 80, right: 40, bottom: 60, left: 100 };
```

**说明**：
- `top: 80` - 增加顶部间距，为标题和图例留出更多空间
- `left: 100` - 增加左侧间距，为更长的Y轴标签留出空间

### 2. 重新排列标题和图例

**修改前**：
- 标题和图例在同一行（Y=20-30）
- 导致文字重叠

**修改后**：
```typescript
// 标题 - 放在最上方 (Y=25)
ctx.fillText(`资产趋势 - 前10名 (...)`, padding.left, 25);

// 最后更新时间 - 放在标题右侧 (Y=25)
ctx.fillText(`更新: ${...}`, width - padding.right, 25);

// 图例 - 放在标题下方 (Y=45开始)
const legendY = 45;
```

**说明**：
- 标题和更新时间在第一行（Y=25）
- 图例从第二行开始（Y=45），每行间距22px
- 避免了文字重叠

### 3. 改进Y轴刻度显示

**修改前**：
```typescript
ctx.fillText(`$${(value / 1000).toFixed(0)}K`, padding.left - 10, y + 4);
```

问题：
- 所有数值都除以1000并显示为"K"
- 例如：100000 → "100K"，101000 → "101K"
- 当数值接近时，显示结果相同

**修改后**：
```typescript
// 根据数值大小选择合适的格式
let label = '';
if (value >= 1000000) {
  // 百万以上：显示到万位
  label = `${(value / 10000).toFixed(1)}万`;
} else if (value >= 10000) {
  // 万以上：显示到千位
  label = `${(value / 10000).toFixed(2)}万`;
} else if (value >= 1000) {
  // 千以上：显示完整数值
  label = value.toFixed(0);
} else {
  // 千以下：显示小数
  label = value.toFixed(2);
}

ctx.fillText(label, padding.left - 10, y + 4);
```

**说明**：
- **百万以上**（≥1,000,000）：显示为"100.0万"，保留1位小数
- **万以上**（≥10,000）：显示为"10.00万"，保留2位小数
- **千以上**（≥1,000）：显示完整数值"1000"
- **千以下**（<1,000）：显示小数"999.99"

**示例**：
- 1,234,567 → "123.5万"
- 123,456 → "12.35万"
- 12,345 → "1.23万"
- 1,234 → "1234"
- 123.45 → "123.45"

### 4. 同步鼠标事件处理

更新 `handleMouseMove` 函数中的padding值，确保与绘图逻辑一致：

```typescript
const padding = { top: 80, right: 40, bottom: 60, left: 100 };
```

## 修复效果

### 布局改进
✅ **标题清晰**：标题独占一行，不再与图例重叠  
✅ **图例整齐**：图例从第二行开始，排列整齐  
✅ **更新时间**：显示在右上角，不影响其他元素

### Y轴刻度改进
✅ **数值清晰**：每个刻度都能看出明显区别  
✅ **精度合适**：根据数值大小自动选择合适的显示格式  
✅ **空间充足**：左侧间距增加，标签不会被截断

## 技术要点

### Canvas绘图顺序
1. 清空画布
2. 绘制网格和坐标轴
3. 绘制趋势线
4. 绘制标题和图例（最后绘制，确保在最上层）

### 文字对齐
- 标题：左对齐（`textAlign = 'left'`）
- 更新时间：右对齐（`textAlign = 'right'`）
- Y轴标签：右对齐（`textAlign = 'right'`）
- X轴标签：居中对齐（`textAlign = 'center'`）

### 字体大小
- 标题：16px bold
- 图例：11-12px（选中时加粗）
- Y轴标签：11px
- X轴标签：10px
- 更新时间：11px

### 数值格式化
使用条件判断选择合适的显示格式，确保：
- 大数值不会太长
- 小数值保留足够精度
- 相近数值能够区分
