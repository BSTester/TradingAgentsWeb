# 前端间隔时间验证更新

## 修改内容

更新前端的分析间隔验证规则，从 **5-60分钟** 改为 **5-120分钟**。

## 修改文件

**文件**: `web/frontend/src/components/intraday/ControlPanel.tsx`

### 1. 输入框限制

```tsx
// 修改前
<input
  type="number"
  min={5}
  max={60}  // ❌ 旧限制
/>
<p className="text-xs text-text-tertiary mt-1">
  系统每隔多少分钟执行一次分析（最低5分钟，最高60分钟）
</p>

// 修改后
<input
  type="number"
  min={5}
  max={120}  // ✅ 新限制
/>
<p className="text-xs text-text-tertiary mt-1">
  系统每隔多少分钟执行一次分析（范围：5-120分钟，默认60分钟）
</p>
```

### 2. 验证逻辑（两处）

```tsx
// 修改前
if (interval < 5 || interval > 60) {
  onShowToast('分析间隔必须在5-60分钟之间', 'error');  // ❌ 旧提示
  return;
}

// 修改后
if (interval < 5 || interval > 120) {
  onShowToast('分析间隔必须在5-120分钟之间', 'error');  // ✅ 新提示
  return;
}
```
