# 智能盯盘移动端布局优化

## 问题描述

在移动端，"参加排名"开关和"实时连接"状态指示器挤在一起，导致布局拥挤，用户体验不佳。

## 解决方案

### 1. 连接状态优化

**桌面端**：显示图标 + 文字
```
● 实时连接
```

**移动端**：只显示图标（添加title提示）
```
●
```

### 2. 间距优化

**修改前**：
```tsx
space-x-4  // 所有屏幕都是16px间距
```

**修改后**：
```tsx
space-x-2 sm:space-x-4  // 移动端8px，桌面端16px
```

### 3. 信息图标优化

**修改前**：所有屏幕都显示

**修改后**：
```tsx
hidden sm:block  // 移动端隐藏，桌面端显示
```

### 4. 文字大小优化

**参加排名文字**：
```tsx
text-xs sm:text-sm  // 移动端12px，桌面端14px
```

## 代码修改

### 连接状态指示器

**修改前**：
```tsx
<div className="flex items-center px-3 py-1 rounded-full text-sm">
  <span className="w-2 h-2 rounded-full mr-2" />
  {isConnected ? '实时连接' : '连接中'}
</div>
```

**修改后**：
```tsx
<div 
  className="flex items-center px-2 sm:px-3 py-1 rounded-full text-sm"
  title={isConnected ? '实时连接' : '连接中'}  // 添加tooltip
>
  <span className="w-2 h-2 rounded-full sm:mr-2" />
  <span className="hidden sm:inline">  // 移动端隐藏文字
    {isConnected ? '实时连接' : '连接中'}
  </span>
</div>
```

### 容器间距

**修改前**：
```tsx
<div className="flex items-center space-x-4">
```

**修改后**：
```tsx
<div className="flex items-center space-x-2 sm:space-x-4">
```

### 信息图标

**修改前**：
```tsx
<div className="relative group">
  <i className="fas fa-info-circle text-text-tertiary cursor-help" />
```

**修改后**：
```tsx
<div className="relative group hidden sm:block">  // 移动端隐藏
  <i className="fas fa-info-circle text-text-tertiary cursor-help" />
```

## 响应式断点

使用Tailwind的 `sm` 断点（640px）：

| 屏幕宽度 | 样式 |
|---------|------|
| < 640px | 移动端样式 |
| ≥ 640px | 桌面端样式 |

## 优化细节

### 1. 内边距调整

```tsx
px-2 sm:px-3  // 移动端8px，桌面端12px
```

减少移动端的内边距，节省空间。

### 2. 间距调整

```tsx
space-x-2 sm:space-x-4  // 移动端8px，桌面端16px
mr-1 sm:mr-2            // 移动端4px，桌面端8px
```

所有间距在移动端减半，避免拥挤。

### 3. 文字隐藏

```tsx
<span className="hidden sm:inline">实时连接</span>
```

移动端只显示状态图标，节省空间。

### 4. Tooltip提示

```tsx
title="实时连接"
```

移动端虽然不显示文字，但通过title属性提供提示（长按可见）。

## 状态指示

### 连接状态图标

| 状态 | 颜色 | 动画 | 文字（桌面端） |
|------|------|------|---------------|
| 已连接 | 绿色 | 脉冲 | 实时连接 |
| 连接中 | 黄色 | 脉冲 | 连接中 |
| 错误 | 黄色 | 无 | 轮询模式 |
| 未连接 | 灰色 | 无 | 未连接 |

### 移动端交互

- **点击**：无交互（仅状态显示）
- **长按**：显示tooltip（浏览器原生）
- **视觉**：颜色和动画提供状态反馈

## 可访问性

### 1. Tooltip支持


- 移动端长按显示

### 2. 视觉反馈

- 颜色区分状态（绿/黄/灰）
